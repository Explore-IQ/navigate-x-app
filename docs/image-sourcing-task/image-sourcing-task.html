How to create a FREE Cloudinary account (Option B or for reference)

1
Go to cloudinary.com

Visit cloudinary.com and click Sign Up for Free. No credit card required.

2
Create your account

Enter your name, email, and a password. Confirm your email via the verification link sent to your inbox.

3
Note your Cloud Name

After login, your dashboard shows your Cloud Name (e.g. my-cloud-123). Share this with the developer — it's needed to construct image URLs.

4
Open the Media Library

Click Media Library in the left sidebar. This is where you'll upload all images. You can create folders here to organise them.

Free plan limits: 25 GB storage · 25 GB bandwidth/month. For ~48 tourism photos this is more than enough.
📸 How to Download from Unsplash
1
Search the place name

Go to unsplash.com and type the place name in the search bar (e.g. "Valley of Flowers India"). Use the search hints in the Places List below.

2
Choose landscape, scenic shots

Prefer wide landscape photos that show the place clearly. Avoid portraits, crowds of people, or heavily text-overlaid images. Bright, natural lighting is best.

3
Download the largest size

Click the photo → click the Download button (arrow icon, top right) → when prompted, choose the largest available size. This is usually 4000–6000px wide.

4
Rename the file before uploading

Rename the downloaded file to follow the naming convention below before uploading to Cloudinary. This saves re-naming work later.

Image quality guidelines

Hero image (1 per place) Wide landscape shot of the landmark/scenery. Min 1600px wide, landscape orientation (16:9 or wider). Should work as a full-bleed background.
Gallery images (3 per place) Mix of angles — wide establishing shot, detail shot, atmosphere shot. Min 800px wide. Can be portrait or landscape.

⬆️ Uploading to Cloudinary Console
1
Log in to Cloudinary

Go to console.cloudinary.com and sign in with the shared credentials.

2
Open Media Library

Click Media Library in the left sidebar. You'll see the asset browser where all images are stored.

3
Create the folder structure

Click the + New Folder button and create this structure:

tourism/ ├── og/ (1 image — social share preview for page.tsx) ├── home/ (15 images — hero, destination cards, gallery for HomeClient.tsx) └── places/ ├── hampi/ ├── marina-beach/ ├── valley-of-flowers/ ├── spiti-valley/ ├── kerala-backwaters/ ├── ranthambore/ ├── andaman-islands/ ├── munnar/ ├── ellora-caves/ ├── coorg/ ├── pondicherry/ ├── ziro-valley/ ├── taj-mahal/ ├── jaisalmer-fort/ ├── goa-beaches/ ├── varanasi-ghats/ ├── golden-temple/ ├── mysore-palace/ └── leh-ladakh/
4
Upload images to each folder

Navigate into the folder for a place (e.g. tourism/places/hampi/), click Upload (top right), drag and drop or select the renamed files for that place.

5
Verify the upload

Once uploaded, click the image to confirm it looks correct — sharp, correct orientation, right place. The Public ID shown in the panel will look like: tourism/places/hampi/hampi-hero

🏷️ File Naming Convention

Rename files on your computer before uploading. Use lowercase, hyphens only — no spaces, no underscores, no uppercase.

Format {place-id}-hero.jpg {place-id}-gallery-1.jpg {place-id}-gallery-2.jpg {place-id}-gallery-3.jpg
Example — Hampi hampi-hero.jpg hampi-gallery-1.jpg hampi-gallery-2.jpg hampi-gallery-3.jpg

🔗 How the URLs Work (For Reference)

You don't need to construct URLs — the developer does this. But this is what a Cloudinary URL looks like once your image is uploaded:

// Hero image for Hampi https://res.cloudinary.com/duajyized/image/upload/f_auto,q_auto,w_1600/tourism/places/hampi/hampi-hero.jpg // Gallery image https://res.cloudinary.com/duajyized/image/upload/f_auto,q_auto,w_800/tourism/places/hampi/hampi-gallery-1.jpg
Cloudinary auto-optimises: f_auto picks the best format (WebP/AVIF), q_auto compresses without visible quality loss, w_1600 resizes to the needed width. You just upload the original large file — Cloudinary handles the rest.
💻 Where the Code Changes Go

Once images are uploaded to Cloudinary, two files need to be updated in the codebase to swap out the old placeholder URLs.

lib/mock-places.ts — place image data

This file holds all 12 places. Each place has an imageUrl (hero) and a gallery array (3 images). Replace the Unsplash URLs with Cloudinary URLs for each place.

// BEFORE — Unsplash placeholder { id: 'hampi', imageUrl: `https://images.unsplash.com/photo-1469474968028-56623f02e42e?w=900`, gallery: [ `https://images.unsplash.com/photo-1506905925346-21bda4d32df4?w=800`, `https://images.unsplash.com/photo-1501854140801-50d01698950b?w=800`, `https://images.unsplash.com/photo-1447752875215-b2761acf3dfa?w=800`, ], } // AFTER — Cloudinary (once uploaded) { id: 'hampi', imageUrl: `${CDN}/${Q},w_900/tourism/places/hampi/hampi-hero.jpg`, gallery: [ `${CDN}/${Q},w_800/tourism/places/hampi/hampi-gallery-1.jpg`, `${CDN}/${Q},w_800/tourism/places/hampi/hampi-gallery-2.jpg`, `${CDN}/${Q},w_800/tourism/places/hampi/hampi-gallery-3.jpg`, ], }
This needs to be done for all 12 places — 48 URL replacements total in this one file.
app/HomeClient.tsx — home page destination cards & gallery

This file has 16 changes: the cloud name on line 19 plus 15 individual image paths. Each path contains a version ID (v1781095104) and a public ID (the filename) that are specific to the old account — they will be different after uploading to the new account.

// Step 1 — Line 19: update cloud name const CDN = 'https://res.cloudinary.com/new-cloud-name/image/upload'; // Step 2 — Update all 15 image paths (version ID + public ID change) // BEFORE const HERO_IMG = `${CDN}/.../v1781095104/subash-matheswaran-OFpmoFFc63c-unsplash_r1uudy.jpg`; // AFTER (new account will have a different version ID and path) const HERO_IMG = `${CDN}/.../v{new-version}/tourism/home/hero.jpg`;
